# Scribe

메뉴바에서 **Antigravity · Gemini**와 **Claude Code** 토큰 사용량을 보여 주는 macOS 앱입니다. 쓴 토큰만큼 고전 작품을 한 글자씩 써 나갑니다.

## 보여 주는 것

- 메뉴바: 픽셀 깃펜 아이콘 하나. 쓰는 중이면 깃펜이 움직이며 줄을 긋고, 돌발 상황으로 멈추면 그 상황의 아이콘과 서 있는 깃펜이 번갈아 보입니다. 토큰 숫자는 팝오버 하단의 사용량 줄에서 봅니다.
- 팝오버: 지금 쓰는 작품(작가 초상화, 제목, 원고 끝부분, 진행). 아래쪽 "창고"과 "서재"를 누르면 팝오버 옆에 패널이 열립니다. 맨 아래 사용량 줄에 설정에서 선택한 에이전트(`Antigravity` / `Claude Code` / `통합`)의 오늘 토큰·비용과 요약 고리가 보이고, 누르면 옆에 사용량 화면이 열립니다. 섹션마다 카드로 나눠 오늘 합계(어제, 지난 7일 평균과 함께), 에이전트별 세션 현황 또는 한도 고리, 오늘 시간대별 막대, 최근 14일 막대와 평균선(막대에 마우스를 올리면 섹션 제목 줄에 그 값), 오늘 모델별 비율과 비용, 토큰 종류(입력·출력·캐시 쓰기·캐시 읽기) 비율을 보여 줍니다.
- 상시 창(설정에서 켬): 알약과 미니 두 모양 가운데 설정에서 고릅니다(창을 오른쪽 클릭해도 바꿀 수 있습니다). 미니는 바탕 없이 둥근 초상화와 진행 고리, % 꼬리표만 떠 있고 오른쪽 위 깃펜이 움직이면 쓰는 중입니다. 알약은 가로로 긴 모양. macOS 26 이상은 리퀴드 글래스 바탕이고, 그 아래 버전은 반투명 재질입니다. 왼쪽에 둥근 작가 초상화와 둘레의 진행 고리, 오른쪽에 제목과 작가 이름, 지금 쓰는 문장 한 줄이 나옵니다. 초상화는 몇 초마다 눈을 깜빡이고 숨 쉬듯 살짝 움직이며, 돌발 상황에는 눈을 감고 상황 문장과 아이템 버튼이 나옵니다. 설정의 "대표 초상화"에서 작가를 고르면 초상화만 그 작가로 바뀝니다.

## 집필

100만 토큰마다 1,000자를 씁니다. 집필 기록은 처음 켠 시점부터 시작하므로, 그 전에 쓴 토큰으로 책이 미리 써지지는 않습니다.

작가 8명(셰익스피어, 디킨스, 포, 캐럴, 스티븐슨, 와일드, 오스틴, 괴테)의 43편을 작가가 번갈아 나오도록 차례로 씁니다. 순서와 글자 수는 `Books/manifest.json` 에 있습니다. 끝나면 2회차로 처음부터 다시 씁니다.

로그는 15초마다 다시 훑고(바뀐 파일만 읽습니다), 늘어난 글자는 4초쯤에 걸쳐 타자기처럼 나타납니다. 돌발 상황은 끝나는 시각에 맞춰 바로 반영합니다. "서재"는 작가마다 한 줄에 초상화와 이름, 그 아래 작품들을 분량만큼 넓은 책등으로 늘어놓습니다. 탈고한 책은 색이 꽉 차 있고, 쓰는 중인 책은 쓴 만큼 아래부터 차오르며 책갈피가 꽂혀 있습니다. 책등을 누르면 위 칸에 제목과 원제, 상태가 나오고, 쓴 것이 있으면 "원고 읽기"로 지금까지 쓴 원고를 창에서 읽을 수 있습니다. 아직 안 쓴 작품은 "다음에 쓰기"로 지금 책 바로 다음에 당겨 오거나, "○○ 몰아 쓰기"로 그 작가의 남은 작품을 이어 쓰게 할 수 있습니다(회차마다 순서를 저장합니다). "성과"는 받은 뱃지와 다음 목표입니다. "창고"은 가진 아이템과 쓰임새, 다음 아이템까지 남은 토큰, 최근 돌발 상황 8개(언제, 몇 분, 어떻게 끝났는지, 멈춘 동안 쓴 토큰)를 보여 줍니다.

### 탈고와 주간 돌아보기

작품 하나를 끝내면 알림이 오고 팝오버에 하루 동안 탈고 카드(걸린 날수, 돌발 상황 수, 재해로 잃은 글자)가 남습니다. 새 주가 되면 지난주(월~일)에 쓴 글자, 탈고, 돌발 상황, 재해, 가장 많이 쓴 날을 모은 카드가 뜨고 소리 없는 알림이 한 번 옵니다. 둘 다 "닫기"로 치웁니다.

### 성과

기록 파일에 있는 값으로 셀 수 있는 성과 66가지가 있고, 이루면 동·은·금 뱃지를 받습니다. 집필(첫 문장, 원고 1만~500만 자, 하루 1만·10만 자, 7·30·100일 개근), 탈고(첫 탈고부터 스물다섯 권, 서재 완주, 작가 8명의 전집), 돌발 상황(처음 겪기, 아이템 쓰기, 커피 열 잔, 기다림, 수집가), 자연재해(생존, 불굴, 잿더미에서, 방재로 막기), 토큰(하루 1억·5억·10억), 그 밖에 밤의 작가(밤 10시~새벽 5시 1만 자), 주말 작가, 두 바퀴, 팔방미인(작가 8명 모두 탈고), 독자(원고 읽기), 편애(몰아 쓰기), 교환상, 끈기(거절 뒤 다시 권해 통함), 손님 많은 집, 선금의 맛, 그리고 이루기 전에는 조건을 가리는 비밀 성과 8가지입니다. 원고 1만·10만·100만 자처럼 단계로 이어진 것은 아직 못 받은 다음 단계 하나만 보여 줍니다. 하루 1만·10만 자와 하루 1억·5억·10억 토큰은 매일 자정에 초기화되는 성과라 날마다 다시 이룰 수 있고, 이룬 날수와 연속 일수를 셉니다. 이룰 때마다 아이템 1개를 받고 금 뱃지의 효과는 그날만 붙습니다. 나머지는 한 번 이루면 끝이고 아이템을 받습니다(동 1개, 은 2개, 금 3개, 종류는 무작위). 금 뱃지는 작은 효과가 계속 붙습니다. 원고 100만·500만 자는 100만 토큰당 글자 5%·10% 더, 폭풍 집필·서재 완주·10억 토큰은 아이템에 드는 토큰 10%씩 덜(폭풍 집필과 10억 토큰은 그날만), 한 달 개근과 산전수전은 돌발 상황 확률 20%·10% 덜, 백일은 돌발 상황 25% 짧게, 열 권·스물다섯 권은 아이템 거절 확률 5%p씩 덜, 5억 토큰은 그날 거절 뒤 기다림 절반, 불굴은 자연재해 손실 절반, 작가 전집은 그 작가를 쓸 때 돌발 상황 15% 짧게입니다. 성과 화면 위쪽 "지금 받는 효과"에 받은 효과가 모입니다. 이루는 순간 macOS 알림이 오고(보상과 효과도 적힙니다. 한꺼번에 여러 개면 알림 하나), 팝오버의 "성과"에서 모아 봅니다. 이 기능이 처음 생겼을 때 이미 이룬 것은 알림 없이 채웁니다. 목록은 `Achievements.swift` 에 있습니다.

### 행운

돌발 상황의 반대편입니다. 새 토큰 100만 개마다 1.5% 확률로 셋 중 하나가 옵니다. "영감의 날"은 60분 동안 글자가 2배로 늘고, "출판사 선금"은 그 자리에서 아이템 3개를 주고, "손님 작가"는 다른 작가가 찾아와 3시간 동안 돌발 상황이 생기지 않습니다(초상화 모서리에 손님이 작게 보입니다). 시작할 때 알림이 오고 팝오버에 노란 띠로 남은 시간이 보이며, 창고의 기록에도 남습니다. 수치는 `Balance` 의 `luckChancePerMillion`, `inspirationMultiplier`, `inspirationMinutes`, `guestMinutes`, `advanceItems` 입니다.

### 작가 기분(눈치·농땡이)

사용자가 손을 뗀 지 얼마나 됐는지(macOS 의 마지막 입력 뒤 지난 시간, 권한 없음, 무엇을 쳤는지는 모릅니다)와 토큰 흐름을 15초마다 봅니다. 사용자는 쓰는데 토큰이 10분 넘게 없으면 작가가 곁눈질하며 "쓸 거리가 없어 펜을 돌립니다" 같은 한 줄을 하고(눈치), 사용자가 15분 넘게 없는데 토큰이 들어오면 "주인이 없어도 쓰고 있습니다"(혼자), 둘 다 30분(설정에서 15·30·60분) 넘게 조용하면 의자에 기대 창밖을 보며 종이비행기를 접습니다(농땡이). 손이 닿으면 바로 "오셨군요" 하고 돌아옵니다. 조건은 30초(2번) 연속 맞아야 바뀌고, 같은 상태가 이어지면 10분마다 새 말을 하며 같은 말은 하루 두 번까지입니다. 돌발 상황 중과 손님 작가가 있는 동안은 없고, 화면이 잠겨 있거나 깬 직후 30초는 판정하지 않습니다. 글자·아이템·판매에는 영향이 없습니다. 설정 집필 탭에서 끌 수 있고, 비밀 성과 "들켰다"(농땡이 중 돌아오기 10번)가 있습니다. 문구는 `Mood.swift` 에 있습니다.

### 잠금 화면

화면이 잠긴 동안 글자가 늘면 60분(설정에서 30·60·120분)마다 지금 작품의 진행률, 늘어난 글자, 그동안의 돌발 상황 수를 알림으로 보냅니다. macOS 알림이라 잠금 화면에 보이며, 시스템 설정 > 알림 > Scribe 의 "잠금 화면에 표시"가 켜져 있어야 합니다. 돌발 상황·행운·탈고 알림도 그대로 잠금 화면에 뜹니다.

### 판매

탈고한 책은 토큰을 쓰는 만큼 팔립니다. 새 토큰 100만 개마다 책 한 권에 기본 10부이고, 탈고한 지 30일 안은 신간이라 3배에서 서서히 내려오며, 손님 작가가 와 있으면 입소문으로 2배, 날마다 조금 흔들립니다. 돈은 없고 부수와 단계만 있습니다. 1,000부 초판 완판, 1만 부 재판, 10만 부 베스트셀러, 100만 부 밀리언셀러이고, 단계를 넘으면 소리 없는 알림이 오고 서재 책등에 띠가 붙습니다(재판 은색, 베스트셀러부터 금색). 서재 작품 칸에 "12,340부 · 재판", 서재 위에 모두 몇 부, 지난주 돌아보기에 지난주 부수가 보이고, 성과 "판매" 묶음(첫 천 부·재판·베스트셀러·밀리언셀러, 십만·백만 독자, 인기 작가, 전작 재판)이 있습니다. 서재 위에는 탈고 수와 모두 팔린 부수, 탈고한 책을 많이 팔린 순서로 늘어놓은 "진열대"가 있고, 작품 칸에는 부수와 다음 단계까지 남은 부수가 막대로 보입니다. 수치는 `Balance` 의 `copiesPerMillion`, `freshDays`, `guestSalesMultiplier` 입니다.

### 선택지가 있는 사건

새 토큰 100만 개마다 0.8% 확률로(앞 사건 뒤 3시간은 쉬고) 작가에게 결정할 일이 생깁니다. 제목을 바꾸자는 편집자, 연재로 쪼개자는 출판사, 비평가의 초대, 쌓인 팬레터, 삽화가의 제안, 해외 출판 제안, 휴가를 바라는 작가, 낡은 펜, 라이벌의 신작, 제자가 되고 싶다는 청년, 초상화를 그리겠다는 화가, 강연 요청, 창틀의 고양이, 집세를 올리겠다는 집주인, 표절 시비, 시끄러운 이웃, 헌사를 부탁하는 후원자, 문학제 초청까지 18가지이고 선택지는 모두 55개입니다. 팝오버의 배너와 macOS 알림의 버튼으로 고르면 결과 한 줄이 나오고(선택지마다 결과 문장이 여럿이라 매번 다릅니다), 몇 시간 동안 판매·글자·돌발 상황 확률·거절 확률 가운데 하나둘에 보정이 붙거나 아이템이 오가며, 팝오버 진행 막대 아래 작은 알약으로 남은 시간이 보입니다. 2시간 안에 답이 없으면 작가가 알아서 고르고 그 결과를 알립니다. 목록은 `Dilemmas.swift`, 확률은 `Balance.dilemmaChancePerMillion` 입니다.

### 서점과 비평

팝오버의 "서점"은 서재·창고와 같은 모양의 패널입니다. "매대"는 탈고한 책을 많이 팔린 순서로 선반에 꽂은 그림입니다(위에 서평 별점). 책등을 누르면 꼬리표에 부수와 판매 단계 사다리(초판 완판 1,000부 → 재판 1만 부 → 베스트셀러 10만 부 → 밀리언셀러 100만 부)가 나오고, 단계 이름에 마우스를 올리면 뜻이 나옵니다. "서평"은 비평가가 쓴 글, "사건"은 사건에 어떻게 답했는지, "풍문"은 판매·서평·사건·돌발 상황·손님 기록에서 뽑은 소문 몇 줄(한 주 동안 같고 월요일마다 바뀝니다)입니다.

비평은 탈고할 때마다 가상의 비평가 8명 가운데 하나가 씁니다. 별점은 하루에 쓴 글자, 돌발 상황 수, 재해로 잃은 양으로 정하고 무작위가 조금 섞입니다. 글은 문장 틀에 낱말을 끼워 짓습니다. 첫인상(별점마다 8가지), 살펴본 대목(문장·인물·결말·첫 장·대화·호흡·구성 … 15가지)에 대한 평(세기별로 7~8가지, 별점에 따라 칭찬과 흠을 섞음), 집필 사정(돌발 상황·재해·걸린 날수)이나 전작과의 비교·권하는 독자, 비평가 문체의 마무리 순서로 서너 문장이 되고, 이름과 제목을 끼운 자리의 조사(이/가, 은/는, 을/를, 과/와, 으로/로)는 받침에 맞춥니다(`Format.resolve`). 같은 조건에서도 매번 다릅니다. 2시간에서 36시간 뒤에 실리고, 실리면 알림이 오며, 그 책은 별점대로 더 팔리거나 덜 팔립니다(★1 0.7배 ~ ★5 1.3배). 실릴 때 그 책의 작가가 쓰는 중이면 작가가 영향을 받습니다. ★5 는 하루 동안 글자 15% 더와 돌발 상황 30% 덜, ★4 는 글자 8% 더, ★2 는 거절 10%p 더와 돌발 상황 20% 더, ★1 은 거절 20%p 더, 돌발 상황 40% 더, 글자 10% 덜이고, 작가가 신문을 액자에 넣거나 찢는 한 줄이 같이 나옵니다. 성과에는 "서점" 묶음(별 다섯, 스크랩북(비평 10편), 결단·편집장(사건에 답하기))과 비밀 성과 혹평이 있습니다. 문구는 `Reviews.swift` 와 `Chatter.swift` 에 있습니다.

### 초상화 꾸미기, 클릭 대사, 말다툼

성과를 이루면 장신구가 열립니다. 외알 안경(첫 탈고), 안경(독자), 귀 뒤 깃펜(원고 10만 자), 실크해트(다섯 권), 월계관(서재 완주), 금관(십만 독자), 꽃(첫 천 부), 나비넥타이(커피 열 잔), 목도리(일주일 개근), 파이프(기다림)이고, 설정 상시 창 탭의 "초상화 꾸미기"에서 작가마다 하나씩 씌우면 상시 창·팝오버·서재의 초상화에 모두 보입니다(`Decor.swift`).

상시 창의 초상화를 누르면 작가가 한마디 합니다. 돌발 상황 중이면 그 상황의 말, 답을 기다리는 사건이 있으면 그 얘기, 방금 비평을 받았으면 그 기분, 눈치·농땡이 중이면 변명, 새벽과 밤, 탈고 직전과 첫 장, 가방이 비었거나 가득 찼을 때의 말이 있고, 나머지는 작가마다 다른 말과 공통의 말에서 고릅니다. 몇 초 안에 연달아 누르면 "그만 찌르세요" 합니다. 비밀 성과 참견(30번)이 있습니다.

손님 작가가 머무는 동안은 25분쯤마다 둘이 한 마디씩 말다툼합니다. 둘의 조합에 맞는 말 16가지(셰익스피어와 와일드, 포와 캐럴, 디킨스와 오스틴 …)와 누구와도 쓰는 말 14가지가 있고, 주인의 말은 상시 창 한 줄로, 둘의 말은 팝오버에 15분 동안 보입니다. 글자에는 영향이 없고 비밀 성과 앙숙(5번)이 있습니다.

### 날씨

날마다 날씨 하나가 정해집니다(날짜로 난수를 고정하고 계절마다 비중이 다릅니다). 맑음, 흐림, 비, 폭풍, 눈(겨울), 안개(봄·가을), 더위(여름)이고, 팝오버 머리에 아이콘과 이름이 보이며 마우스를 올리면 효과가 나옵니다. 비는 글자 5% 더와 돌발 상황 10% 덜, 폭풍은 자연재해 확률 2.5배와 판매 15% 덜, 눈은 손님 작가가 못 오고(대신 선금) 돌발 상황 10% 덜, 안개는 판매 15% 덜, 더위는 돌발 상황 20% 더, 맑음은 판매 5% 더입니다. 상시 창에는 날씨 색이 옅게 깔리고 비와 눈이 내립니다. `Weather.swift` 에 있습니다.

### 영감 게이지

입력·캐시 토큰은 작가가 "읽는 것"으로 쳐서 영감 게이지에 쌓입니다(글자는 지금처럼 모든 토큰으로 씁니다). 1.5억 토큰이 차면 알림이 오고 팝오버 진행 막대 아래 "영감 켜기" 버튼이 생기며, 누르면 행운의 영감의 날과 같은 효과(60분 동안 글자 2배)가 켜지고 게이지는 0이 됩니다. 행운이 진행 중이면 못 켭니다. 성과 "불씨"(세 번 켜기)가 있습니다. 수치는 `Balance.inspirationGaugeTokens` 입니다.

### 마감

월요일마다 출판사가 이번 주 과제를 냅니다. 지난주 글자의 1.1배(5천·1만 자 단위로 올림, 최소 1만 자), 남은 분량이 지난주 글자의 1.2배 안이면 "이번 주 안에 탈고", 탈고한 책이 있고 지난주에 팔린 게 있으면 지난주 부수의 1.2배 가운데 하나입니다. 탈고 과제는 그때 쓰던 책의 제목을 답니다("크리스마스 캐럴 탈고"). 팝오버 진행 막대 아래 한 줄로 진행이 보이고, 목표에 닿으면 바로 아이템 2개와 판매 20% 보정(하루)을 받습니다. 지킨 뒤에는 "마감 지킴 · 크리스마스 캐럴 탈고 · 화"처럼 과거형으로 하루 동안 보이고 사라지며, 다음 과제는 월요일에 옵니다. 일요일까지 못 지키면 거절 확률이 이틀 동안 10%p 오르고 편집자의 편지가 한 줄로 옵니다. 과제가 나올 때와 결과가 날 때 알림이 오고, 지난주 돌아보기에 지켰는지 적힙니다. 성과 마감 사수·믿을 만한 작가와 비밀 성과 펑크가 있습니다. 수치는 `Balance` 의 `deadline*` 입니다.

### 작가 교대와 카페인

책이 다음 작가 차례로 넘어가면 상시 창에서 떠나는 작가가 일어나 의자가 비었다가(1.6초) 새 작가가 앉습니다(3.2초). 둘이 한 마디씩 주고받는데(둘의 조합에 맞는 말 10가지, 누구와도 쓰는 말 12가지), 오는 작가의 말은 상시 창에 3분, 두 줄은 팝오버에 15분 동안 보입니다. 문구는 `Chatter.swift` 의 `Handoffs` 에 있습니다.

하루에 커피·홍차로 돌발 상황을 5번 넘게 끝내면 카페인이 돕니다. 상시 창 초상화의 손이 떨리고 타자가 2.2배 빨라지며, 팝오버 머리에 잔 수가 주황색으로 보입니다. 그날은 졸음 대신 글이 막히고, 다음 날은 돌발 상황이 생길 때 25% 확률로 졸음이 됩니다. 비밀 성과 "카페인"(하루 7잔)이 있습니다. 수치는 `Balance` 의 `caffeineCups`, `hangoverNapChance`, `caffeineTempo` 입니다.

### 작업실, 출판사, 내기

창고의 "작업실"에서 아이템으로 가구를 들입니다. 탁상등(새 초 3·등잔 2, 밤 글자 +10%), 난로(커피 3·잉크병 2, 겨울 돌발 상황 -20%), 책장(연필 3·사본 2, 판매 +5%), 두꺼운 커튼(금고 2·호출 종 2, 폭풍 날 재해 확률 절반), 안락의자(홍차 3·오르골 1, 거절 -5%p), 고양이(심부름꾼 2·홍차 2, 돌발 상황 -5%, 창틀의 고양이 사건 없음). 한 번 사면 계속이고 초상화 뒤 책상 장면에 그려집니다(책장은 오른쪽 위, 커튼은 창 양옆, 난로는 왼쪽, 탁상등은 책상 오른쪽, 고양이는 창턱). 성과 집들이·안락한 작업실이 있습니다.

탈고하면 카드에서 원고를 어디에 보낼지 고릅니다. 대형 출판사(선금 아이템 3개, 신간 보정 최대 3배), 문예 출판사(선금 없음, 비평 점수 +0.5, 신간 보정 최대 2배), 독립 출판(선금 없음, 신간 기간 60일, 보정 최대 2배). 하루 안에 안 고르면 대형으로 갑니다. 비평의 별점은 이 때문에 실리는 순간 정합니다. 성과 출판사 세 곳이 있습니다.

손님 작가가 와 있을 때 말다툼 차례에 30% 확률로 내기를 겁니다. 손님이 가기 전까지 정해진 글자(평소 속도로 그 시간에 쓸 양의 1.2배, 최소 2,000자)를 채우면 아이템 3개와 판매 +50%(하루), 못 채우면 아이템 2개를 잃습니다. 팝오버 배너나 알림 버튼으로 받거나 사양합니다. 비밀 성과 도박사(3승)·쪽박(3패)이 있습니다.

### 서점 관리

서점 화면은 메인 화면과 같은 틀입니다. 머리에 서점 장면(창문·책장·주인, 시간대와 날씨를 따라감)과 오늘·모두 부수, 서평 수, 진열창의 책, 주인의 신뢰 단계가 있고 오른쪽에 이번 주 부수가 크게 있습니다. 그 아래는 지금 살아 있는 것이 칩 한 줄로 보입니다. 지난주 정산서, 독자 주문, 품절·재판 중인 책, 광고 중인 책, 서점 사건의 보정. 칩을 누르면 그것만 아래에 카드로 펼쳐지고 다시 누르면 접힙니다. 손댈 일이 있는 칩(정산서, 당겨 올 수 있는 독자 주문)에는 점이 붙습니다. 끝나면 사라지고 없으면 줄 자체가 없습니다. 매대 자리에는 탈고한 책이 자리별(진열창·매대·서가·창고)로 작은 칩에 담기고, 하나를 누르면 아래 꼬리표가 그 책으로 바뀝니다. 꼬리표에 재고와 자리, "진열창"·"매대"·"광고 걸기" 버튼이 있습니다. 그 아래 한 줄 둘은 지난 14일 판매 막대와 최근 서점 소식이고, 발의 "서평", "소식", "풍문", "정산"을 누르면 그 목록이 아래에 펼쳐집니다. 가끔 독자가 아직 안 쓴 책을 주문합니다(새 토큰 100만 개마다 0.6%). 7일 안에 그 책을 쓰기 시작하면(배너의 "다음에 쓰기"로 당겨 올 수 있습니다) 신간 기간 동안 50% 더 팔리고 주인의 신뢰가 오릅니다. 기한을 넘기면 신뢰가 내립니다. 성과 독자의 부탁·광고주가 있습니다.

### 서점 운영

현실 서점에서 판매를 좌우하는 네 가지를 그대로 옮겼습니다. 재고가 있는가, 어디에 놓였는가, 주인이 밀어주는가, 정산이 어떻게 나오는가.

재고와 재판. 탈고하면 견본 100부가 서점에 들어오고, 출판사를 고르면 초판이 들어옵니다(대형 3,000부, 문예 1,000부, 독립 300부). 팔릴 때마다 재고가 줄고 0이 되면 품절이라 안 팔립니다. 그때 출판사에 재판을 청하는데 부수는 지난 7일 판매의 1.5배(초판의 0.5~4배 사이)이고, 들어오기까지 대형 6시간, 문예 12시간, 독립 24시간입니다. 품절 중에 온 손님은 놓친 손님으로 셉니다. 품절과 입고는 알림과 팝오버·상시 창 한 줄로 알려 줍니다. 서점 사건도 재고를 탑니다. 학교 주문·낭독회 같은 큰 판매는 재고만큼만 나가고, 반품은 창고로 돌아오고(젖은 책과 쥐가 갉은 책은 못 씀), 창고 상자는 재고를 더하고, 인쇄소 지연은 기다리던 재판을 늦춥니다. 광고는 품절인 책에는 못 겁니다.

진열 공간. 진열창 1칸(1.3배), 매대 2~5칸(제값), 서가(절반), 창고(품절)입니다. 주인이 아침 8시 뒤 처음 반영할 때 자리를 다시 정리하고, 빈 칸이 생기면(품절·입고·탈고) 바로 채웁니다. 어느 책을 앞에 둘지는 점수로 정합니다. 지난 7일 판매 속도에 신간 보정(첫 이레는 지금 제일 잘 나가는 책만큼 팔릴 것으로 봄), 서평 별점, 광고 중 2배, 독자 주문 책 1.5배를 곱하고, 한자리에 이레 넘게 있던 책은 조금씩 깎으며, 주마다 조금 다른 눈으로 봅니다. 그래서 신간은 앞에 서고 오래된 책은 돌아가며 자리를 내줍니다. 직접 고를 수도 있습니다. 꼬리표의 "진열창"(하루에 한 번, 신뢰가 안면 이상)과 "매대"(칸이 차 있으면 주인이 고른 책 중 가장 덜 팔리는 것이 내려감)로 올리면 직접 고른 자리가 되어 이레 동안 주인이 안 건드립니다. 올라 있는 책을 다시 누르면 서가로 내리고 이레 동안 주인이 다시 올리지 않습니다. "주인에게 맡기기"로 거둘 수 있습니다.

주인의 신뢰. 0~100이고 40에서 시작합니다. 서먹함(0~19), 안면(20~39), 보통(40~59), 친근함(60~79), 단골 작가(80~)로 나뉘고 매대 칸이 2, 3, 3, 4, 5칸, 진열창은 안면부터, 재판은 친근함이면 15%, 단골이면 30% 빨리 옵니다. 독자 주문을 지키면 +5, 놓치면 -5, 매대나 진열창의 책이 품절되면 -2, 반품이 오면 -3, 낭독회·사인본·다과회·독서 모임·작가 초상이 잘 끝나면 +2, 광고를 걸면 +1, 정산 때 놓친 손님이 5% 아래면 +4, 30% 넘으면 -4, 한 주 내내 손님이 없으면 -1입니다. 머리의 점 다섯에 올리면 최근 사유가 보입니다.

월요일 정산서. 월요일에 주인이 지난주를 셈해 보냅니다. 책마다 팔린 부수, 반품, 놓친 손님, 남은 재고, 자리와 신뢰 변화의 사유, 주인의 한마디("품절로 돌려보낸 손님이 많았습니다. 재판을 미리 청했으면 더 팔았을 겁니다"). 서점 맨 위 배너로 보이고 "펼치기"로 책별 줄을, 발의 "정산"으로 최근 넷을 봅니다. 알림도 옵니다(소리 없음). 옛 기록은 처음 반영할 때 탈고한 책마다 출판사 초판만큼 재고를 채워 품절로 시작하지 않습니다. 수치는 `Shop.swift` 의 `Balance` 확장(`windowSales`, `shelfSales`, `sampleRun`, `pinDays`, `reprint*`, `trust*`)과 `Publisher` 의 `firstRun`, `reprintHours` 입니다.

### 서점 사건

탈고한 책이 있으면 새 토큰 100만 개마다 1.2% 확률로 서점에 일이 생깁니다. 예순여섯 가지이고, 상황에 따라 나오는 것이 다릅니다. 주말에만(휴일 특수), 서평 별 4개 이상인 책이 있을 때만(서평 재조명, 문학상 후보), 비·눈·안개·더위·폭풍일 때만(비 피하는 손님, 눈에 갇힌 손님, 안개 낀 밤, 더위 피난처, 폭풍 휴업, 눈길, 젖은 책), 그 달에만(연말 선물, 봄 축제, 피서객, 긴 밤, 새해 결심), 밤에만(밤늦은 손님, 등불 아래), 탈고한 책이 여럿일 때만(전집 수집가, 매대 앞자리, 뒷선반, 전집 할인) 나오는 것이 있습니다. 효과는 여섯 가지입니다. 책 하나나 전부의 판매에 3~24시간 붙는 배수(0.4~2배), 한 번에 늘어나는 부수(1~300), 돌아오는 부수(반품·젖은 책·창고의 쥐), 오가는 아이템(독자의 선물, 좀도둑, 세금 징수원), 영감 게이지(밤늦은 손님 10%, 독자 편지 15%), 주인이 책을 이달의 책으로 거는 것(등불 아래, 매대 앞자리. 이미 걸린 책이 있으면 대신 1.2배가 6시간), 손님이 다음 책을 예약해 독자 주문이 생기는 것(예약 손님). 두고 간 책, 옆집 개, 멈춘 시계, 조용한 날처럼 아무 효과 없이 지나가는 날도 있습니다. 생기면 상시 창과 팝오버에 3분 동안 한 줄이 보이고, 서점의 소식 줄과 "소식" 목록에 남으며, 꼬리표에 "사건 +50%"처럼 붙습니다. 알림은 보내지 않습니다. 문구와 조건은 `Studio.swift` 의 `ShopEvents` 에 있고 성과 단골 서점(20번)이 있습니다.

### 집필 화면 구성

머리 카드에는 초상화와 제목·작가, 상태 줄(쓰는 중·날씨·커피), 오른쪽에 큰 진행률과 그 옆에 작은 고리 둘(체력 붉은색, 영감 금색)이 있습니다. 원고 카드 아래 진행 줄은 "쓴 글자 / 전체 · 오늘 +n자 · 탈고까지"입니다. 그 아래 상태 한 줄은 영감·체력·능력치·보정을 요약하고 누르면 펼쳐집니다(설정값 `writingStatusExpanded`). 영감이 찼으면 저절로 펼쳐지고, 체력이 지치거나 영감이 차면 그 항목에 색이 붙습니다. 마감은 상태 줄 위에 늘 보입니다. 발은 마을 아이콘과 창고·성과·서재·서점 넷입니다. 설정의 기록 탭 서재 항목에 원서 출처(Project Gutenberg, 괴테 번역자)를 적어 두었습니다.

### 체력과 능력치

작가마다 체력과 능력치 다섯이 있습니다. 교대하면 그 작가 것으로 바뀝니다. 체력은 100에서 시작해 새 토큰 100만 개마다 1.2씩 줄고 한 시간에 4씩 돌아옵니다. 밤(22~5시)과 쉬는 동안(돌발 상황 중)은 두 배로 돌아오고, 글을 안 쓰는 작가도 돌아옵니다. 30% 아래로 떨어지면 지쳐서 글자가 30% 덜 늘고 초상화가 피곤한 표정이 됩니다. 0이 되면 탈진해 3시간 긴 의자에 눕습니다. 커피로 깨울 수는 있지만 자주 거절하고, 깨어나면 체력이 절반은 돌아와 있습니다. 커피·홍차로 상황을 끝내면 체력이 15 돌아옵니다. 능력치는 필력(글자 +2%/단계), 끈기(최대 체력 +5, 소모 -3%), 매력(그 작가 책 판매 +2%), 감각(서평 별 +0.1, 영감 게이지 +3%), 운(아이템 간격 -1.5%, 행운 확률 +3%)이고, 새 토큰 2천만 개마다 하나가 무작위로 1 오릅니다(20까지). 탈진 중 토큰은 세지 않습니다. 오르면 팝오버와 상시 창에 "포의 필력이 3이 됐습니다. 문장이 전보다 빨리 나옵니다"처럼 한 줄이 보입니다. 메인 화면 영감 게이지 옆에 체력 줄, 그 아래에 능력치 칩 다섯과 다음 상승까지 남은 토큰이 있고, 올리면 지금 효과와 다음 효과가 보입니다. 수치는 `Stats.swift` 의 `Balance` 확장(`stat*`, `stamina*`, `pen*`…)에 있습니다.

### 마을

팝오버에서 방향키를 누르면 작은 맵이 열립니다(집필 제목 옆 지도 단추로도 엽니다). 게임보이 컬러 시절 포켓몬 마을의 그림 관습을 따랐습니다. 바닥은 옅은 민트색에 회색 점, 마을 둘레는 네 단계 초록으로 빽빽한 나무 덤불, 지붕은 검은 테두리 안에 세로 줄무늬 두 줄과 처마 선, 벽은 옅은 바탕에 벽돌 점, 창문은 노란 유리에 검은 틀, 색은 그 시절 팔레트 값입니다. 그림 자체는 직접 그린 것이고 게임 타일을 옮기지는 않았습니다. 작업실(초록 지붕, 창 둘, 문)·창고(갈색 지붕, 널빤지 쌍여닫이 문, 앞에 상자)·서점(파란 지붕에 책 간판, 책등이 보이는 큰 진열창) 세 건물이 나란히 서 있고, 사용자를 뜻하는 노란 모자에 빨간 윗옷 차림이 바닥에 서 있습니다(세 방향 서 있는 모습과 걷는 모습 둘, 오른쪽은 왼쪽을 뒤집음). 방향키로 걷고, 문 앞에서 ↑나 Return 을 누르면 그 화면이 열립니다. 작업실은 팝오버의 집필 화면, 창고는 아이템 패널, 서점은 서점 패널입니다. 건물을 클릭해도 들어가고 Esc 나 × 로 닫습니다. 바닥을 클릭하면 그 칸까지 걸어가고, 사람이나 물건을 클릭하면 그 앞까지 가서 말을 겁니다. 마을이 열려 있을 때는 WASD 와 Space 도 됩니다. Return 은 바라보는 것이 없으면 옆에 있는 것에 말을 걸고, 그것도 없이 문 앞이면 들어갑니다. 손님과 나무, 팻말은 지나갈 수 없습니다. 손님 네 사람은 생김새가 다릅니다. 단골 할아버지는 납작한 모자에 흰 콧수염, 학생은 까만 머리에 책가방, 비평가 지망생은 베레모와 안경, 장꾼은 챙 넓은 밀짚모자입니다. 작업실 문 오른쪽에는 5시간 한도가 남은 만큼 장작이 0~6개 쌓이고(한도를 못 읽으면 없음), 장작더미 앞에서 Return 을 누르면 남은 몫과 초기화 시각이 나옵니다. 아래 발 버튼은 그대로 있어서 맵은 또 하나의 길일 뿐입니다. 맵 아래에는 살롱이 있습니다. 맵이 네 줄 늘어 14×12 타일이고, 가운데 아래 자두색 지붕 건물이 살롱입니다. 문으로 들어가면 작가들이 모인 방이 열립니다. 벽난로, 책장 둘, 긴 탁자에 의자 일곱. 탈고한 적이 있는 작가들이 서재 순서로 앉아 있고(지금 쓰는 작가와 와 있는 손님 작가는 빼고), 처음엔 한둘이다가 서재가 차면 일곱이 됩니다. ←→ 로 작가를 고르면 머리 아래에 "말 걸기"가 뜨고 Return 으로 말을 겁니다. 말은 자기 책의 부수·단계·서평, 지금 쓰는 작가에게 전하는 한마디(말다툼 문구), 그 작가다운 말(초상화를 눌렀을 때의 대사), 살롱 잡담을 돌아가며 합니다. 작가들끼리도 7~9초마다 둘이 말다툼 문구를 번갈아 말풍선으로 띄웁니다. 말 끝에 "같이 쓰자고 청하기"가 있어서 고르면 그 작가가 손님 작가로 작업실에 옵니다. 하루 한 번, 행운이 없을 때만이고, 응할 확률은 50%에 매력 한 단계마다 5%p(최대 90%)입니다. 사양하면 한마디 하고 끝입니다. Esc 로 나오면 맵의 살롱 문 앞에 섭니다. `Scribe --salon out.png` 로 낮과 밤을 그려 볼 수 있고, 방과 말은 `Salon.swift` 에, 수치는 `Balance` 의 `invite*` 에 있습니다. 맵은 16px 타일 14×12 를 1.5배(레티나에서 그림 한 점이 기기 픽셀 셋)로 한 장의 비트맵으로 구워 두고(상태가 바뀌면 다시 굽고 캐시) 걷는 사람과 손님, 말풍선만 따로 얹어서, 가만히 있을 때는 아무것도 다시 그리지 않습니다. 맵은 지금 상태를 비춥니다. 서점 앞에는 재고가 있으면 손님 한 사람이 서 있고 좋은 서점 사건과 광고마다 한 사람씩 줄이 길어지며(넷까지), 진열된 책이 모두 품절이면 한 사람이 돌아섭니다. 품절이면 서점 옆에 팻말이 서고, 광고 중이면 벽보가 붙습니다. 작업실은 밤에 글 쓰는 중이면 창문에 불이 켜지고 돌발 상황 중이면 꺼지며, 돌발 상황이나 방금 난 재해는 지붕 위 말풍선에 아이콘으로 뜹니다. 창고 앞 상자는 아이템 수에 따라 0~3개입니다. 손님들은 제자리 둘레 두 칸 안에서 때때로 돌아서거나 한 칸 걷고(문 앞과 사람 자리는 피함), 글 쓰는 중이면 작업실 굴뚝에서 연기가 오르고, 꽃은 0.5초마다 흔들리고, 20초마다 새 한 마리가 하늘을 가로지릅니다. 문 앞에서 ↑를 누르면 문이 열리고 한 칸 걸어 들어가며 화면이 어두워진 뒤 그 화면이 열립니다. 사람과 손님 발밑에는 그림자가 있고, 맵에는 상시 창과 같은 그 시각의 색(새벽·노을·밤)이 옅게 덮입니다. 밤에는 게임의 밤처럼 전체가 푸르게 가라앉고 서점 창에 불이 켜집니다. 날씨도 모두 비칩니다. 비·폭풍·눈은 맵 위에 내리고, 비·폭풍이면 사용자와 손님이 우산을 쓰며, 폭풍은 어둡다가 8초쯤마다 번개로 한 번 하얗게 번쩍이고, 안개는 흰 띠가 천천히 흐르며 위쪽이 뿌옇고, 흐림은 전체가 조금 가라앉은 위로 구름 그림자가 느리게 지나가고, 더위는 바닥이 누렇게 바래고 누런 빛이 돌며 손님이 하나 줄고, 눈 오는 날은 바닥·지붕·나뭇잎이 하얗게 덮입니다. `Scribe --village out.png --weather` 로 여섯 날씨를 한 장에 그려 볼 수 있습니다. 맵에서는 앞에 선 것이 있으면 사람 머리 위에 작은 검은 표시가 떠서 지금 Return 으로 할 수 있는 일("말 걸기", "우체통 열기", "들어가기", "줍기")을 알려 줍니다. 아래 안내 줄은 기본 조작만 적습니다. Return 을 누르면 게임의 글상자처럼 흰 상자에 말이 뜹니다(Return 다음 쪽, Esc 닫기, 선택지는 ←→ 로 고름). 손님 넷은 저마다 다릅니다. 단골 할아버지(느리게 어슬렁, 옛날 얘기와 풍문), 학생 손님(바쁘게 돌아다니고 베스트셀러·다음 책 얘기), 비평가 지망생(서평과 문체를 평함), 장꾼(품절·광고·날씨와 장사 얘기). 말은 지금 상태(진열창 책, 서평 별, 오늘 부수, 날씨, 최근 서점 사건, 독자 주문, 신뢰 단계)로 채워지고 거듭 말을 걸면 바뀝니다. 손님 말 끝에는 "책 권하기"가 있어 고르면 진열창·매대 책 하나를 3~12부 사 가고 신뢰가 조금 오릅니다(하루 세 번). 작업실 창문 앞에서 Return 이면 작가가 창가에 나와 상시 창 초상화를 눌렀을 때의 그 말을 하고, 서점 진열창 앞이면 주인이 신뢰·진열창 책·재고·오늘 부수를 말합니다. 우체통은 기다리는 편지(독자 주문, 출판사 답, 정산서, 마감)를 읽어 주고, 팻말은 오늘·이번 주 부수와 품절 재판 시각을, 창고 상자는 아이템 목록을 보여 줍니다. 하루에 한 번 풀밭 어딘가에 반짝이는 물건이 떨어지고 밟으면 아이템 하나를 줍습니다. 문구는 `VillageTalk.swift` 에, 수치는 `Balance` 의 `recommend*` 에 있습니다. 걷기는 키를 누르고 있는 동안 타일 사이를 픽셀로 이어 가고(한 칸 0.17초, 앞 반 걷는 그림·뒤 반 선 그림), 손님과 연기·꽃·새는 맵이 보일 때만 움직입니다. `Scribe --village out.png` 로 낮과 밤을 그려 볼 수 있고, 그림과 걷기는 `Village.swift` 에 있습니다.

### 자연재해

새 토큰 100만 개마다 0.4% 확률로 화재, 홍수, 폭풍, 지진 가운데 하나가 일어납니다. 집필은 멈추지 않고, 지금 쓰는 책 분량의 1~4%만큼 원고를 잃습니다. 이 책에서 쓴 것보다 많이 잃지는 않아서 탈고한 책은 그대로입니다. 잃은 글자는 그날 기록의 `lost` 로 남고, macOS 알림과 팝오버 한 줄(1시간), 상시 창 한 줄(3분), 창고의 최근 기록으로 알려 줍니다. 금고나 사본이 막았으면 "지진이 났지만 금고 덕에 원고는 무사했습니다"로 알립니다. 수치는 `Balance` 의 `disasterChancePerMillion`, `disasterLoss` 입니다.

### 돌발 상황과 아이템

새 토큰 100만 개마다 3.5% 확률로 작가에게 돌발 상황이 생깁니다(졸음, 잉크 떨어짐, 자리 비움, 산책, 글이 막힘, 밀린 편지, 밤에는 촛불 꺼짐, 그리고 작가마다 하나씩 있는 일). 상황이 있는 동안은 집필이 실제로 멈춥니다. 그동안 쓴 토큰은 글자가 되지 않습니다. 상황마다 원인이 하나 붙습니다(예: 자리 비움 → "문밖에 손님이 찾아왔습니다"). 상황은 15~60분 뒤 저절로 끝나며 그때 돌아온 말("손님을 배웅하고 책상으로 돌아왔습니다")이 팝오버와 상시 창에 3분 동안 보이고 소리 없는 알림이 한 번 옵니다. 맞는 아이템을 쓰면 바로 끝나지만, 25% 확률로 작가가 거절합니다("종소리는 들었지만 조금만 더 있겠다고 합니다"). 거절하면 아이템은 그대로고 3~5분 뒤에 다시 권할 수 있으며, 같은 상황에서 거절당할수록 다음엔 10%p씩 덜 거절합니다. 알림의 "아이템 권하기" 버튼으로 권했을 때는 통했는지 거절당했는지 알림으로 한 번 더 알려 줍니다. 문구는 `AuthorEvents.swift` 에, 확률은 `Balance.refusalChance` 에 있습니다.

아이템은 토큰 2,500만 개마다 하나씩 얻습니다(멈춘 동안 쓴 토큰도 셉니다). 하루 4억 토큰이면 16개쯤이고, 돌발 상황이 하루 14번쯤이니 상황 하나에 아이템 하나 남짓입니다. 한 종류는 5개까지 가지며, 가득 찬 종류는 추첨에서 빠지고 모두 가득이면 그 아이템은 없던 일이 됩니다(성과 보상과 선금도 같습니다). 역할이 여섯 가지이고 역할마다 아이템이 둘씩입니다. 깨우기(커피, 홍차), 잉크(잉크병, 연필), 불러오기(호출 종, 심부름꾼), 영감(영감의 깃펜, 오르골), 불빛(새 초, 등잔), 방재(금고, 사본). 같은 역할이면 어느 것이든 그 상황을 끝내고, 두 번째 아이템은 문구가 다릅니다. 방재 아이템은 자연재해가 나면 저절로 하나가 쓰여 원고를 지킵니다. 창고에서 같은 아이템 3개를 다른 아이템 하나로 바꿀 수 있습니다.

초상화도 상황에 따라 바뀝니다. 졸면 눈을 감고 Z가 뜨고, 잉크가 떨어지면 빈 잉크병을 내려다보고, 자리를 비우면 빈 의자만 남고, 촛불이 꺼지면 어둠 속에 눈만 빛납니다.

알림 글은 제목 한 마디(무슨 일인지, 작가 이름은 조사까지 맞춰 "포가 돌아왔습니다")와 두 문장 안의 본문으로 맞췄습니다. 알림은 1분 안에 여러 개가 생기면 "소식 n건" 하나로 묶고(아이템을 권할 수 있는 돌발 상황 알림은 바로 보냅니다), 설정의 방해 금지 시간(기본 23시~8시)에는 모아 두었다가 끝나면 요약 한 번만 보냅니다. 모아 둔 동안은 팝오버에 "방해 금지 · 소식 n건"으로 보입니다. 상황이 생기면 macOS 알림이 한 번 뜨고(처음에 알림 권한을 묻습니다. ad-hoc 서명이라 거절되면 시스템 설정 > 알림에서 Scribe 를 켜야 하고, 그 전까지는 스크립트 편집기 이름으로 가는 간이 알림입니다. 설정의 "알림" 탭에서 상태를 보고 시험 알림을 보낼 수 있습니다), 맞는 아이템이 있으면 알림의 "아이템 쓰기" 버튼으로 바로 쓸 수 있습니다. 팝오버와 창고에는 배너와 아이템 버튼이, 상시 창에는 상황 한 줄과 버튼이 나옵니다. 수치는 `AuthorEvents.swift` 의 `Balance` 한곳에 있습니다.

원문은 [Project Gutenberg](https://www.gutenberg.org) 의 퍼블릭 도메인 영어 텍스트이고, 앞뒤 안내문과 Project Gutenberg 표기를 떼어 `Books/` 에 넣었습니다. 앱으로 묶을 때는 `scripts/pack-books.swift` 가 zlib 로 압축해(11MB → 4.4MB) `Resources/Books/*.txt.z` 로 넣고, 앱은 `.txt` 가 없으면 `.txt.z` 를 풀어 읽습니다. 읽은 원문은 글자 배열이 아니라 문자열 그대로 두고 64글자마다 자리를 적어 두어(가장 긴 책 120만 자도 본문 1.2MB + 표시 150KB), 쓰는 책과 읽기 창에 연 책 둘까지만 기억하고 나머지는 비웁니다. 괴테는 독일어로 썼기 때문에 19세기 영어 번역본(보일런, 베이어드 테일러, 스완윅, 프로싱엄, 보링, 칼라일)을 넣고 번역자 서문은 뗐습니다. 한국어 번역본은 번역자 저작권이 있어 넣지 않았습니다. 원문은 영어지만 제목·작가 이름과 나머지 표현은 한국어로 보여 주고, 원제는 마우스를 올리면 나옵니다. 작가 초상화는 24×24 픽셀 그림(`PortraitArt.swift`)이고, 얼굴 자리가 같아 표정(웃음·찡그림·피곤·놀람)과 장신구를 한 규칙으로 얹습니다. 비평 별점, 아이템 거절, 재해, 카페인, 새벽에 따라 표정이 바뀝니다. 초상화 뒤에는 책상 장면이 있어 왼쪽 위 창문에 그때의 하늘(해·달·비·눈)이, 책상에 잉크병과 초가 보이고, 잉크가 떨어지면 병이 쓰러지고 촛불이 꺼지면 연기가 납니다. 팝오버 머리에는 작가 색이 옅게 깔리고, 원고는 크림색 종이 위에 방금 쓴 글자가 잉크 마르듯 진해지며, 돌발 상황 배너는 위에서 내려오고 진행률 숫자와 막대는 미끄러지듯 바뀝니다. 서재 책등은 작가마다 장정 무늬가 다르고 탈고한 책에는 제목 머리글자와 광택이 붙으며, 성과 메달은 묶음마다 모양이 다릅니다(집필 원, 탈고 방패, 판매 동전, 돌발 상황 육각, 자연재해 둥근 네모, 토큰 마름모). 메뉴바 깃펜은 탈고 직후 20초 동안 별이 반짝이고 카페인이 돌면 떨립니다. 상시 창의 한 줄(돌아온 말, 행운, 기분, 재해)이 폭보다 길면 2초 멈췄다가 천천히 옆으로 옮겨 끝까지 보여 주고 되돌아옵니다. 상시 창 바탕에는 그 시각의 색이 깔립니다. 시각마다 정한 색(깊은 밤 검정, 동트기 전 보라, 해 뜰 때 분홍, 아침 금빛, 낮 하늘색, 오후 누런빛, 해 질 때 주황, 노을 자주, 땅거미 남색, 저녁 남회색) 사이를 분 단위로 이어 붙여 하루 내내 조금씩 바뀌고, 해 뜨는 때와 지는 때는 달에 따라 한 시간쯤 움직입니다(6월엔 늦게 지고 12월엔 일찍 집니다). 해 진 뒤 한 시간 반부터 해 뜨기 한 시간 전까지는 바탕이 어두우니 글자와 진행 고리, 배지를 어두운 모드 색으로 바꾸고, 초상화 색이 가라앉으며 책상 모서리에 촛불이 켜집니다. 색은 유리 효과의 tint 가 아니라 유리 위에 직접 칠해서 또렷이 보이고, 유리는 10분마다 새로 만듭니다. 날씨도 바탕에 깔립니다. 흐림은 위가 짙은 회색, 비는 푸른 회색, 폭풍은 어둡다가 8초쯤마다 번개로 번쩍이고, 눈은 희푸르고, 안개는 흰 띠가 천천히 흐르고, 더위는 위에서 누런 빛이 들며, 비·눈은 그 위에 내립니다. 작가 이름은 짧은 이름(성)만 보여 제목이 길어도 잘리지 않습니다. 글자색은 바탕 밝기로 정합니다. 유리 바탕(시스템 모양)에 시각 색조와 날씨 색을 겹친 밝기를 재서 어두우면 흰 글자(보조 글자는 흰색 80%), 밝으면 검은 글자(보조 64%)를 쓰고, 고리와 배지도 그에 맞춥니다. 시스템의 보조 글자색은 어두운 바탕에서 너무 흐려서 비율을 직접 정했습니다(`PillInk`). `Scribe --hours out.png` 로 시각별 알약을 한 장에 그려 볼 수 있고, 색은 `Portraits.swift` 의 `DayPart.tint(at:)` 에 있습니다.

설정은 팝오버 아래 톱니바퀴를 누르면 다른 패널처럼 팝오버 옆에 뜹니다(위에 제목과 탭 넷, 고른 탭은 다음에도 그대로). 팝오버를 못 찾을 때만 따로 설정 창이 열립니다. 방해 금지 시각은 메뉴 대신 −/＋ 단추로 고릅니다. 메뉴를 열면 팝오버가 닫힐 수 있어서입니다. 내보내기·가져오기는 저장·열기 창을 띄우면 팝오버와 패널이 닫힐 수 있어서, 결과를 알림으로 바로 보내고(방해 금지 중에도) 다음에 기록 탭을 열면 그 줄에도 남겨 둡니다. 확인용으로 `--open-panel settings` 를 주면 뜨자마자 팝오버와 그 옆 패널을 열어 봅니다(shelf·bag·bookstore·badges·usage 도 됨). 다른 앱이 앞에 있으면 팝오버가 안 열릴 때가 있습니다. 설정은 네 탭입니다. "상시 창"(켜기, 알약·미니, 투명도, 대표 작가, 초상화 꾸미기), "집필"(데이터 소스 선택, 금 뱃지 효과가 들어간 지금 규칙, 작가 기분), "알림"(권한, 방해 금지, 잠금 화면), "기록"(데이터 소스 선택, 파일 위치와 내보내기·가져오기, 읽는 로그 폴더, 서재 통계, 버전). 설명은 각 줄에 마우스를 올리면 힌트 카드로 나옵니다. 가져오면 지금 파일은 백업으로 남깁니다. 기록은 `~/Library/Application Support/Scribe/writing.json` 에 날짜별 토큰과 글자 수, 가진 아이템, 진행 중인 상황, 돌발 상황 기록(최근 50개)으로 저장합니다. 저장할 때마다 직전 파일을 `writing.backup.json` 으로 남기고, 읽지 못하는 파일은 덮어쓰지 않고 `writing.broken-<시각>.json` 으로 옮깁니다.

## 데이터를 가져오는 곳 (에이전트 선택)

설정의 **집필** 또는 **기록** 탭 맨 위 **데이터 소스**에서 토큰을 공급받을 에이전트(`Antigravity` / `Claude Code` / `통합`)를 직접 고를 수 있습니다. 에이전트를 바꾸더라도 지금까지 쓴 원고 글자 수는 그대로 보존되며, 바꾼 시점 이후 늘어나는 토큰부터 이어서 씁니다.

| 항목 | 출처 | 비고 |
|---|---|---|
| Antigravity 토큰·비용 | `~/.gemini/antigravity/brain/<conv-id>/.system_generated/logs/transcript.jsonl` | 네트워크나 별도 로그인을 쓰지 않습니다. `step_index` 기준으로 중복을 묶습니다. |
| Gemini CLI 토큰·비용 | `~/.gemini/tmp/<hash>/chats/session-*.json` | 로컬 세션 기록만 읽습니다. |
| Claude Code 토큰·비용 | `~/.claude/projects/**/*.jsonl`, Claude 데스크톱 앱 세션 폴더 | 네트워크를 쓰지 않습니다. `message.id\|requestId` 로 중복을 묶습니다. |
| Claude 한도 % | `https://api.anthropic.com/api/oauth/usage` | 공개되지 않은 API 입니다. Claude Code 모드를 쓸 때만 로그인 토큰을 읽고 갱신하지 않습니다. |

비용은 API 단가로 환산한 추정치이고 구독 요금과는 다릅니다. 1시간 캐시 쓰기는 입력 단가의 2배, 5분 캐시 쓰기는 1.25배로 계산합니다.

## Keychain (Claude Code 사용 시)

Claude Code 로그인은 Keychain 의 `Claude Code-credentials` 항목에 있습니다. 앱은 이 항목을 `/usr/bin/security find-generic-password -w` 로 읽습니다. Claude Code 가 같은 도구로 항목을 만들기 때문에 접근 목록에 이미 들어 있어 암호 창이 뜨지 않고, 앱을 다시 빌드해도 다시 묻지 않습니다. 그래서 5분마다 도는 자동 갱신이 알아서 읽고, 토큰이 만료되거나 거절되면 Keychain 을 다시 읽어 Claude Code 가 갱신해 둔 새 토큰을 씁니다. 새로고침 버튼을 누를 필요는 없습니다. 로그인이 만료되거나 거절돼 한도를 못 읽으면 사용량 화면에 이유와 할 일을 적어 둡니다(만료면 Claude Code 를 한 번 쓰면 되고, 거절되거나 정보가 없으면 터미널에서 `claude auth login`). 앱이 대신 로그인하지는 않습니다. 로그인이 바뀌면 다음 갱신 때 저절로 읽고, 바로 보려면 새로고침을 누르면 됩니다.

토큰은 메모리에만 두고 디스크에 쓰지 않습니다. 확인용으로 `swift run -c release Scribe --limits` 를 실행하면 같은 경로로 한도를 찍습니다(토큰은 찍지 않습니다).

## 설치 및 빌드

### 릴리스 압축본(ZIP / DMG)으로 설치할 때

Apple Developer ID 공증 없이(ad-hoc 서명) 웹에서 내려받은 `Scribe.app` 은 macOS Gatekeeper 가 격리(`com.apple.quarantine`) 속성을 붙여 첫 실행을 막을 수 있습니다. `/Applications` 로 옮긴 뒤 터미널에서 아래 한 줄을 실행하면 정상 실행됩니다:

```bash
xattr -dr com.apple.quarantine /Applications/Scribe.app
open /Applications/Scribe.app
```

### 소스에서 직접 빌드할 때

```bash
./scripts/build-app.sh
open build/Scribe.app
```

배포용 아카이브(`dist/Scribe-<버전>-macos.zip`, `dist/Scribe-<버전>.dmg`, `dist/SHA256SUMS.txt`)를 만들고 셀프테스트까지 검증하려면:

```bash
./scripts/package-release.sh
```

앱 아이콘은 `scripts/generate-icon.swift` 가 만들고, `build/AppIcon.icns` 가 없으면 빌드 스크립트가 자동으로 만듭니다. 원문 폴더 `Books/` 는 앱 안 `Resources/Books` 로 복사됩니다.

화면 없이 집계와 집필 진행을 확인하려면(기록 파일은 읽기만 합니다):

```bash
swift run -c release Scribe --dump
```

임시 폴더에서 기준선, 글자 환산, 돌발 상황 동안 멈춤, 아이템 얻기와 쓰기, 저절로 끝나기를 확인하려면:

```bash
swift run -c release Scribe --selftest
```
